# The Daily Machine Spirit

*In the grim darkness of the far future, no one reads the code.*

A satirical website: one AI-written prayer or ritual to the Machine Spirit every day, for the software habits we follow
without understanding them, each with a **Heretical Truth** that explains what really happens.

Coming to [dailymachinespirit.fyi](https://dailymachinespirit.fyi).
